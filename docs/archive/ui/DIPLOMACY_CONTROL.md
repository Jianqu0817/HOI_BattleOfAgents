# 正常宣战接口（旧桌面版归档）

> 本文记录退役时的实现和命令。当前入口见[工具目录](../../../tools/README.md)。

`diplomacy.declare_war` 将模型的密封决定交给普通游戏外交界面执行，不调用强制战争效果。接口已接入观察、动作校验、逐动作存档、回合恢复和离线验收；本机界面入口与实际宣战仍需由对应发布实测确认。

## 请求与候选

```json
{
  "id": "1-GER-1",
  "type": "diplomacy.declare_war",
  "args": {"target_country": "FRA", "wargoal_id": 123}
}
```

这里的 ID 只是格式示例，必须从当前观察 `diplomacy.action_options` 原样选择。每轮对同一目标最多提交一次宣战。候选包含目标国家、确切存档中的首都州及自己已有战争目标的 ID、类型和名称；当前只向模型开放配置内其他参赛国。

战争目标来自本国 `diplomacy.wargoals`。游戏可能只在其中一国的 `diplomacy.active_relations.TARGET.war_relation` 序列化共享战争记录；程序合并参赛国记录及未选 NPC 的公共战争投影，按双方标签建立战争图。NPC 投影只保留双方、开始日期和双方伤亡，不保留敌军或私密目标。阵营成员读取当前存档的顶层 `faction`，不把态度、战争目标或阵营名称猜成已开战。旧快照缺少完整阵营字段时关闭新宣战候选，等待重新采集。

缺少目标时，`blocked_targets` 解释原因，包括 `no_wargoal`、`same_faction`、`already_at_war` 和首都归属未确认。普通战争目标正当化尚未接入，程序不会替玩家自动制造目标。试验场景可以在开局准备阶段预设并记录目标，但玩家阶段仍必须通过正常宣战界面。

保存了目标不代表宣战已经合法。世界紧张度、政体、附庸、停战协定等条件仍由游戏按钮与确认窗口判定。同一目标有多个同名类型的目标、界面又无法唯一对应其 ID 时，不随机选第一个。

## 执行与证据

执行器从确切存档的目标首都州进入地图，读取州 ID，再左击已确认的拥有国旗帜，严格核对外交页的国家名称。随后只点击游戏明确标为可用的“宣战”项，在正常窗口选择匹配的战争目标，确认“召集盟友”关闭或未提供，最后才点击明确可用的“提交”。无法确认目标、目标选项、盟友开关或按钮状态时停止。

界面截图、目标身份和按钮读取保存在 `ui_result`；只有新存档出现明确包含双方标签的共享 `war_relation`，才确认战争已经生效。无需双方各存一份副本；重复记录必须一致。界面返回成功、政治点数变化或一条通知，都不足以替代战争关系证据。

开发校准可调用 `declare_war(..., preview=True)`，它沿同一路径检查到提交之前，返回 `ready_to_send=true`、`declaration_sent=false` 和截图，将窗口留给操作者关闭；不会点击提交。模型动作参数中没有 `preview`，正式请求默认走实际提交路径。

验证分别报告：

- `effect_status=full`、`new_war=true`：本次动作前尚未开战，之后出现对应共享战争关系。
- `effect_status=already_present`、`new_war=false`、`declaration_sent=false`：执行到本国时，双方已经开战，未再次点击界面。
- `war_pairs_added` 和 `additional_opponents`：此次操作后的实际新增交战关系及额外敌国。保障独立、阵营和既有战争合并可能扩大战争，不能将记录剪成“只对目标国开战”。无法解释的战争关系变化会停止核验。

`already_present` 用于处理同轮密封互宣：例如德国和法国都决定宣战，按执行顺序第一方正常提交，第二方确认已开战后保持状态。两份请求均有明确结果，但只发生一次新宣战。

## 同时决策与恢复

战争、目标和阵营使用独立 `diplomacy_fingerprint` 在整回合开始或恢复检查点核对，不混入每国经济/军队指纹。因此，一个国家正常宣战改变了对手的外交状态，不会使其他国家同一时刻提交的经营请求被误判为私密命令遭篡改。行动执行期间始终以最近的实际存档继续。

中断后先核实原动作的前后存档。已经形成战争的请求标为已生效并跳过；没有任何经济、军队或外交变化时才允许重试。重复战争记录冲突或无法解释的外交变化不能算作未生效后盲目重放。

时钟恢复要求确认对应战争仍在，不能因为原目标消失而再次宣战。如果战争已经正常结束、但当前记录不足以证明结束原因，应暂停人工核实，不自动重新开战。目前仅接入宣战；加入阵营、召集盟友和其他外交行为尚未提供动作接口，也不会靠聊天承诺触发。
