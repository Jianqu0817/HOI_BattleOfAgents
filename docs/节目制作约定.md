# IRON 节目制作约定

## 立绘与构图

- 半身立绘先定遮挡物，再定人物位置。按背景、人物、桌沿或讲台、字幕的顺序合成。裁边要整条藏进不透明的前景里。用对话框遮挡时，留意圆角、左右边距和字幕消失的那一拍。
- 以本期 1280×720 的合照为例，桌沿从画面顶端往下 520 像素处开始，六个人的立绘都延伸到 540 像素处。地图旁的主持人可以直接延伸出画面底边，把地图空间留给观众。
- 导出后抽看一张合照、一张双人接话和一张地图讲解。看最靠边的人和正在听的那个人，再看闭嘴、换人、停顿时有没有露出水平切口。开口差分与闭口差分要对齐。

## 主持与剪辑

- 智谱娘先给新观众讲清游戏和眼下的争点，再给五位玩家留出自由选国、交友和反驳她的时间。剪辑时保留那个让对方接得上话的问题。并行发言按同轮呈现，避免剪成先后因果。
- 先播公开的挑问和回应，再揭已经可以公开的相关目标。讲局势时用对应时点的地图核对玩家说法。本期里，“我同意停火”和存档里“奥意仍在交战”可以放在相邻两镜。总结大会也沿用公开材料。

## 配音与录制

- 每句从该角色自己的参考录音中随机轮换，记录选样以便续做。主持样本避开明显的句首哼笑。保留句间换气和换事件时的看图时间，抽听连续几句才能听出重复的小动作。
- 净地图默认隐藏 HUD。日期从观察 API 或对应存档读取，按镜头时间核对。录制通过项目 API 和 OBS 完成，具体入口见 [AGENTS.md](../AGENTS.md)。
