# 叙事、角色素材与视频制作

当前原生入口仍为 `tools/native_campaign.py`。`configs/campaign.native.example.json` 已启用以下流程；旧对局冻结配置不会被新默认值改写。

## 可见性与表演

公开发言最后经过白名单投影，只带公开事件、公开原话、公开承诺与角色公开设定；不带本国私信、密封计划、私有经验或全知裁判评语。执行结束也不公开命令本身。发言永远是角色主张，不能冒充游戏事实。

每次公开发言可附最多两条 `public_asides`，用 `{about, stance, ref, text}` 对已有公开来源表示支持、质问或吐槽。引用必须来自本次提供的公开证据 ID。它们复用外交请求，不增加模型阶段。

私信只送给收件国。收件国允许在新的私信里自行转述、加工甚至欺骗；系统不自动附送原件，也不认证转述。密封裁判的全知理由仅供观众，玩家只得到本国裁定与请求哈希。

`performance.enabled` 开启密封后的两个独立展示阶段：公开主持人点评、按国家轮换的观众专属采访。默认每轮一国采访，可改 `interviews_per_turn`。主持人的输入仅限公开资料；采访仅限受访者原本可见的信息。使用固定感受问题，不提供战略建议。所有采访在 `performance.json`，不写回玩家记忆，也不修改命令。角色可以拒答或质疑问题。

## 统一自适应时钟

`clock_policy` 默认和平 168 小时、战争 24 小时、重要事件后 6 小时；最长 360 小时。所有国家共用同一个时钟，规划前公布本轮预算。执行按最多 6 小时原生分块观察，中间不调用五个模型。

观察到战争或相关省份控制权变化时，在原生分块完成并暂停后保存，进入新回合。结果中的 `requested_step_hours` 是密封预算，`step_hours` 是实际经过时间，`early_end` 说明提前结束原因。各国密封动作不会因为时间缩短而重发。

未知提前暂停、待决事件或控制国家异常仍暂停等待核对，保留剩余预算与请求 ID。不要换一个请求 ID 重放命令。陆军轨迹独立记录首次观察抵达与终点位置；六小时分块间的短暂经过仍可能漏采。

当前事件 API 只能读取已注册窗口中的原始事件键与选项键，覆盖为 `partial`。完整待决队列、完整本地化正文、选项资格与正常选择命令仍未资格验证；因此不能声称实现了自动选择和无阻挡自动录制。其他窗口只记录，不自动关闭。后续需真实事件实例完成归属、资格与命令效果闭环。

## 记忆、期限与计分

即时提示保留最近两轮；磁盘保存最近十二轮本国记录。较早记忆至多选择六轮、八封本国信件，整体不超过约 24000 字符，避免重复发送最近两轮；超限省略更早完整记录，不截断或改写原话。公开发言不会收到该记忆。结构化承诺优先使用原生游戏小时 `due_date_raw`，兼容旧 `due_turn`。

承诺结算只有五种结果：未到期、条件未满足、不可核实、已履行、可观察地违约。只有显式机器谓词和期限对应的公开事实能确定结论；自然语言条件、预测、无法观察的承诺保持不可核实，不能因为命令未公开就认定背叛。展演、领土增量、目标省份三种既有计分模式均可使用；计分不冒充原版投降判定。

## 六角色与表情

`configs/characters.example.json` 使用 `deepseek / claude / qwen / glm / gemini / gpt` 六个稳定角色 ID。每位五张独立生成的透明 PNG，存放于 `assets/characters/<角色>/<表情>.png`。基础与变体分别由内置 ImageGen 生成；变体沿用基础头像，仅改变表情。生成提示词与文件哈希保留在素材清单。

角色 ID、国家、模型地址分别配置。`configs/production.example.json` 的国家绑定只是演示映射，不意味着该国家已经接入同名厂商模型。`card_file` 暂为空，后续由用户填写角色卡；声线也可以独立替换。无需为换一张角色卡改动执行 API。

## 后期制作操作

原生对局会继续导出原有 `index.html`、字幕、证据时间轴和镜头表。制作配置额外导出：

- `characters.json` 与 `characters/`：复制进素材包的角色图及绑定。
- `voice_lines.jsonl`：剪辑选中片段的逐字台词、角色、可见性、证据 ID；技术回执不会当作角色原话朗读。
- `editing_plan.json`：按事件优先级挑选的确定性剪辑草案、目标时长、保留和省略证据 ID。它不是导演模型生成的叙事。
- `cast.html`：离线角色台词预览，可切换已有表情；配置声音后播放生成 WAV。
- `voice_receipts.json`：每句配音生成、缓存命中或缺素材状态。

既有观众包也可单独添加制作文件：

```powershell
python tools/production.py --episode <已导出的观众包目录> --config configs/production.example.json
```

素材包始终包含全部观众私密内容，不能作为参赛者的上下文。公开播放器需要另行只选公开事件，不能仅隐藏网页中的私密卡片后当作公开数据接口。

发展阶段建议地图延时摄影配总结；事件和冲突恢复原速。实际录屏 UTC、游戏日期、建议剪辑秒数分开保存。草案不捏造录像时间码或加速倍数；先用 OBS 锚点对齐，再填写 `recording_in/out` 和实际倍速。可在剪辑软件里重排证据，但不要把事后采访剪成事前公开发言。

GPT-SoVITS 已部署，详见 [GPT_SOVITS.md](GPT_SOVITS.md)。填写各角色参考音频及准确转录后运行：

```powershell
python tools/start_gpt_sovits.py
python tools/production.py --episode <观众包目录> --config configs/production.example.json --synthesize
```

只对选定冻结台词合成，复用内容缓存；语音时长生成后需在剪辑软件中调整镜头长度。当前没有角色参考录音，服务就绪不等于六个声线已经出声。
