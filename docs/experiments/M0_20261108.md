## 环境与后端

- 正在运行的 Windows HOI4 1.19.4.2，单人、非铁人、中文界面。本轮沿用已有测试局，难度为 easy，包含已有 Mod；它是接口实验，不作为正式比赛条件。

## 已验证的适配

1. 客户区直接截图，避免 DPI 不一致导致顶栏被裁切。
2. 原始渲染坐标到 Windows 客户区坐标的换算。
3. 720p 控制台边框识别，排除顶栏相同颜色的干扰。
4. 控制台输入框显式聚焦，配合虚拟键和粘贴，取得真实游戏回执。
5. 指定国家的 `ai TAG` 返回 `Disabled AI for: TAG`；五国均取得对应回执。
6. 使用 `eval_effect FROM` 输出当前玩家国家到日志；五国切换得到对应国家回执，日期保持一致。
7. 新测试存档保存成功，解析器能从确切文件读取五国状态。

中文日期解析规则已有针对全角标点的测试，但现有字体的 OCR 数字仍有误读。控制实验改用新生成的游戏日志回执日期，并用测试存档交叉检查；不依赖不确定的 OCR 日期。

## 复现与恢复

使用 `tools/m0_probe.py prepare` 建立新实验，再用 `advance` 执行指定的 1–10 轮。国家列表来自 `configs/match.example.json`，可配置 3、4 或 5 个互不重复的国家。

`ai TAG` 是切换命令。prepare 会保存每次切换的意图和回执，并阻止重放同一次准备；`--known-disabled` 只用于已经取得明确停用回执的国家。中断后先读取实验的 report 与实际游戏状态，不能直接重复切换。控制台命令、游戏回执、前后存档路径和最终分析均保存在对应运行目录。
