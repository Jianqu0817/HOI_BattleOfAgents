## 最小命令面板

源码位于 `mod/ironbridge/`，采用公共 API level 2 的 scripted GUI 命名协议，包含序号与参数两个输入框及 opening epoch。Apply 检查 API、epoch、字段数量和字符错误后，将字段长度和字符代码写入本国变量，并输出 `IRON_CAPIE_ACK`。

测试请求使用序号 `7`、参数 `42`。字符表 `0..9` 对应代码 `53..62`，预期序号代码为 `60`、参数代码为 `57,55`。检查游戏日志和保存后的本国变量，两者一致才算桥接通过。
