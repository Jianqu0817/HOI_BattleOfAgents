# DeepSeek 五国半月回合测试

日期：2026-11-08。

## 结果

已完成一轮真实模型驱动的经营回合：同一暂停时刻采集五国观察 → 五国独立公开发言 → 分别提交私密决策 → 裁判模型审查原请求 → 普通界面执行与存档核验 → 共同推进 15 游戏日 → 最终存档复核。

起点为 `1936.3.16.11`，终点为 `1936.3.31.11`。15 次每日检查各精确推进 24 小时，总计 360 小时；最终五国身份回执处于同一日期。游戏已返回德国视角，保持暂停。

## 模型与消息

- 服务：`https://api.siliconflow.cn/v1`。
- 请求与返回模型均为 `deepseek-ai/DeepSeek-V4.1-Flash`。
- 思考模式关闭，temperature 0.3，单次最多 1800 输出 token，JSON object 输出。
- 五个国家使用各自独立的消息上下文，先同时生成公开发言，再统一接收全部公开发言。没有向其他国家提供私密决策或理由。
- 裁判使用单独上下文，审查五份私密请求，并逐项返回原请求 SHA-256 与批准结果。实际执行的请求哈希与批准记录全部一致。
- 正式阶段共 11 次调用：5 次公开发言、5 次私密决策、1 次裁判审查。共 37172 输入 token、1886 输出 token，合计 39058 token，均为服务返回的用量。另有一次 24 token 的连通性测试。

模型将身份字段返回在 `identity` 对象中，适配器仅展开字段位置。五份原始动作、身份值与理由逐项保持一致，未重新抽样或代替模型选择策略。

## 执行与恢复

本轮完成了这些本机中文界面适配：逐条确认控制台输入焦点；消除悬停提示对科研槽读取的遮挡；按科技名称或机型代码定位；对金底白字科技卡片做高对比度识别；滚动寻找视口下方科技；按装备完整名称／简称与可见行位置核验生产目标；跨多个动画帧确认暂停状态。

界面识别失败时保持暂停，并写新存档判断是否产生效果。只有五国玩法指纹均不变，才将尝试判为未应用；已生效的动作在恢复时跳过。最终存档确认五国各有一次成功执行，模型策略未被改写。

20 项离线测试、存档解析器自测和 Python 编译检查通过。两张真实科技树截图另经离线识别复核，正确定位 C.200 与 III 号坦克卡片。

## 当前范围

本轮验证的是经营流程与消息隔离。公开交流是一轮广播，尚未实现多轮往返、两国私聊、长期国家记忆、完整战争迷雾、通用陆军指令、战斗和胜负评估。

模型理由中也有缺少证据的判断：英国、苏联称“建造队列已满”。输入分别有 3、5 项在建项目，但未提供完整的民用工厂总量、空建筑位或队列容量数据，本轮无法核实“已满”这一说法。接口通过与指令生效不能作为策略理解准确的证据；后续观察报告需要进一步区分游戏事实、未知值与执行能力限制。
