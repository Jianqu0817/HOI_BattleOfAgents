## 本次实现

每回合顺序为：同一暂停时刻采集本国观察 → 两轮公开讨论 → 一轮定向私信 → 私密决策 → 裁判审查 → 串行执行和存档验证 → 共同推进。

- 每轮公开发言收齐后统一发布。第二轮各国均收到完整的第一轮五条消息，可以回应具体表态。
- 每国可发送一封定向私信或弃权。本次每回合均发出五封；各国决策只收到自己的发件和收件，其他国家看不到。
- 各国保留最近两回合的本国决策、实际执行结果、公开讨论及本人参与的私信。第三回合还带入本国裁判反馈、已知事实纠正和来源确认的西班牙内战公共新闻。早期历史没有后来新增的反馈字段，按实际旧格式保留。
- 裁判核对原请求的 SHA-256，批准后交给普通操作执行器；不会改写玩家策略。实际执行请求与获批请求逐项一致。
- 科技候选增加年份、基础成本和超前年数。未知建筑容量明确标为未知，接口允许的操作范围与游戏资源上限分别说明。

## 两次实际中断与处理

回合 2 的西班牙内战世界新闻挡住控制台。有效 Mod 事件文件中的 `news.63` 为 `major=yes`；可见选项 `news.63.a` 只有名称与触发条件，没有游戏效果。核实有效脚本、源文件哈希和界面后确认该新闻。恢复程序发现实际已推进 144 小时，而日志只登记 120 小时，补记已发生的 24 小时，再仅推进剩余 216 小时。该回合五个原始动作没有重放。

新增的新闻处理只确认来源唯一匹配、无效果且为全球新闻的可见选项。科研／国策完成提示也可关闭。带效果的事件和不确定的弹窗继续停下，不自动选第一项。

回合 3 在五个动作全部成功、推进之前，切国回执缺失。截图确认下方外交面板的边框被当作控制台边界，导致焦点点击位置偏低。修正本机 720p 识别范围，使用真实故障截图复核输入位置；再通过新日志回执和新存档确认五国状态未变，跳过五个已完成动作，继续推进。
