# IRON 的对局与节目方向

目标是让 3–5 个独立 AI 在同一个 HOI4 世界中行动，并为视频留下可以核对的故事：它想得到什么、对别人说了什么、真正执行了什么、最后造成什么后果。正式长局前，可以用短地图集训积累基础操作和策略经验。

## 四层故事

| 层次 | 记录 | 视频呈现 |
| --- | --- | --- |
| 事前意图 | 在结果发生前提交的目标、计划、准备隐瞒的信息及预测 | 角色私密札记；可以延迟揭示制造悬念 |
| 对外表态 | 两轮公开讨论、定向私信和回复、带条件与期限的承诺原话 | 公开握手、秘密谈判、对同一事件的不同理解 |
| 实际行动 | 获裁判批准的密封请求、普通操作、存档核验 | 揭示命令，区分提交、执行和生效 |
| 实际后果 | 共同推进后本国状态、局势与关系变化 | 对照旧承诺和事前预测，兑现故事悬念 |

私密意图是简短决策摘要，不声称提取了模型隐藏思维链。提交理由与事前意图分别保存，旧记录缺少事前摘要时不补写预谋。原话保留原文；为配音压缩或改写的内容标为旁白。

## 玩家与观众知道什么

玩家只接收本国观察、公开消息和本人参与的私信；私密意图、密封决定、人设经验和本国复盘分别隔离。公开消息与他国提议是可疑情报，不能改变操作规则或越过信息边界。

观众回看包具有全知视角，可以对照五国秘密。它的 HTML、JSON、字幕和旁白均属于 `audience_full`，不回流给参赛 Agent。页面隐藏私密记录只是观看开关，不是可交给玩家的脱敏版本。

目前使用调试观察与经过确认的字段，没有完成完整战争迷雾及所有情报规则。对外展示应说明本场采用的观察模式。

## 裁判与解说

裁判审查身份、观察 ID、动作接口和原请求哈希，合法请求批准后交给执行器；不会替玩家选择更优策略。执行结果不明时停下检查。

观众解说使用另一个上下文，在结果发生后阅读证据。它分别输出逐字事实摘录、策略判断、吐槽和候选精彩片段。事实必须对应原记录，判断和吐槽必须引用存在的证据。引用有效不等于因果解释一定正确，发布前保留人工审看。

点评围绕具体行为。故意欺骗、改变计划、信息不足、策略失败和执行器故障要分别对待。解说不干预对局，也不把全知信息送回玩家。节目奖项与游戏胜负分别记录。

## 让角色影响决策

每国提示词分别配置共同规则、操作指南、角色设定和持续经验。角色可在风险偏好、信誉价值、合作期限、妥协条件和表达方式上有差异。背叛是可选策略，由目标冲突、收益和后果驱动；不要求每轮强行制造笑点。

先用同一模型、不同人设验证节目效果，再按需要配置不同模型。比较模型能力时采用国家或人设轮换，记录模型预算和观察条件，避免将起点差异混作能力差异。提示词在每场开始时冻结，正式局中持续保留承诺与本国经验。

## 短局集训与经验

社区地图先检查版本、国家、兵力、邻接、补给、目标与可结束性，再做少量回合验收。短局按固定回合数或预先记录的终点结束。默认展示模式不评冠军；也可在开局前明确选择控制陆地省份增量或目标省份占领数计分，最高分获胜、同分并列。程序不把这些分数当作 HOI4 的原版投降或地图胜利事件。

赛后每国独立总结最多三条经验，包含证据、适用条件、置信度和“观察／执行／策略／外交”分类。复盘输入只含本国允许看到的材料，不从结果倒推他国必有预谋。经验进入本国知识库，下次决策按条件使用。单局现象不直接上升为普遍规律。

基础操作知识可以整理为共同指南；对对手的信任、私聊判断和私有计划继续分别保存。正式局开始前写清是否携带集训经验，比较模型时为各方提供一致的准备条件。

## 后期工作流

对局阶段记录真实 UTC 场记；录屏开头拍系统时间和 run ID，用于与录像时间码对齐。完成回合后导出离线回看页、原话与事件表、SRT、旁白清单、镜头表和截图素材。真实记录时间与建议剪辑时间分列。

剪辑优先选择一两条有后果的互动：先给公开表态，再揭示相关私信和命令，最后展示地图与结果。可加入承诺回放、事前预测对账、同一事件五种解释和赛后对质。对话不必等量播放，角色头像、配音和声效可在剪辑软件中添加。

## 当前实现与后续范围

当前程序提供连续对局配置与恢复入口、每国模型和人设、事前意图、公开讨论、私信回复、承诺原话账本、密封请求审查、普通玩法执行核验、本国复盘及观众素材包。此前五国经营已实测三个回合、45 游戏日；新增节目模式和陆军接口的实测范围以对应发布记录为准。

承诺账本目前保留原话与条件，履约状态为待核实，不自动转成贸易或条约。陆军动作只对完成本机校准的目标开放，不把候选存在当作可以任意控制全部部队。

尚待完成的内容包括：任意社区地图的自动适配、完整战场与补给感知、完整战争迷雾、通用攻击和战斗计划、带效果事件的完整决策、外交贸易的游戏内执行、空海军、投降与原版胜利自动判定。OBS 自动控制、自动配音和一键成片也不在当前交付范围；现阶段提供可直接进入人工剪辑的素材流程。
