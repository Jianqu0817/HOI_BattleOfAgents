# IRON 舞台分层素材

**学院讲堂大屏修订版：**按用户反馈新增普通学院讲堂方案，地图显示面积约为本版战况解说场景的2.3倍，人物与简洁讲台位于右侧。见 [学院讲堂素材](academy/README.md)，下载后打开 `academy/index.html` 浏览。本目录下的原白金议事厅素材保留供对比。

本组舞台采用明亮的象牙白、金色雕饰、蜂蜜色木材和藏蓝幕布，与现有角色的赛璐璐风格相配。五张绘制素材使用用户指定的4K模型标识 `gpt-image-2.5-4k`，实际原图均为 **3840×2160**。

## 建议叠加顺序

1. 后景建筑。
2. 在实体屏幕内放游戏画面，用对应 `screen_masks` 限制显示区域。
3. 发言者柔光层。
4. 角色立绘；发言者保持正常亮度，其他角色适当压暗，位置保持稳定。
5. 透明讲台前景，形成自然的前后遮挡。
6. 后续若需姓名或字幕，单独添加文字层；它们没有烘焙进舞台图片。

两种屏幕在生成图中偏宽，示例采用等比完整显示，使用藏蓝侧边留白保留整个16:9游戏画面及HUD，不拉伸、不裁掉游戏信息。屏幕遮罩按实际生成图校准，不依赖提示词中的理想尺寸。

## 构图参数

- 双人厅：左右人物中心分别为615、3225像素，示例立绘高度1858、底部2117；双讲台前景下移300像素，使讲台靠近镜头。
- 解说厅：人物中心3264像素、高度1793、底部2073；保留左侧屏幕的完整可视区域。
- 单人近景：使用现有角色立绘上部960像素，展示高度1900、中心1920、底部2150；单讲台下移500像素，避免遮挡书本。
- 坐标均基于3840×2160画布。其他尺寸应统一按比例缩放所有层。

## 静态示例复现

从项目根目录运行：

```powershell
.venv/Scripts/python.exe tools/stage_preview.py --theme classic
# 替换成自己保存的真实游戏截图
.venv/Scripts/python.exe tools/stage_preview.py --theme classic --game-frame "C:/captures/hoi4.png"
```

该工具只做本地静态合成，不启动游戏、不调用模型、不生成语音或视频。默认读取项目既有角色PNG及本包 `examples/hoi4_saved_frame.png`；首次在本机生成示例时，该帧从之前的录制验收包复制。传入 `--game-frame` 可替换为自己保存的截图。单独下载素材包即可浏览所有示例，重新合成则需项目角色库。

`council_left_speaking.png` 与 `council_right_speaking.png` 展示发言者切换；`briefing_presenter.png` 展示地图主导的解说构图；`speaker_close.png` 展示单人近景。

屏幕里的示例图来自此前暂停的HOI4画面，不是新回合、实时直播或模型绘制的游戏事实。原始后景的屏幕保持空白，可在未来接入真实截图或录屏。当前只交付舞台图片、遮罩及静态构图示例，不恢复剪辑、配音或对局运行。
